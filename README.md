# My Opportunity Tracker

## Project Description

My Opportunity Tracker is a web application that helps users organize and track opportunities such as scholarships, internships, jobs, and other applications.

Users can add opportunities, update their application status, manage deadlines, and monitor their progress.

## Features

- Add new opportunities.
- Select opportunity types.
- Record deadlines and next actions.
- Update opportunity status.
- Delete opportunities.
- View progress summary.
- Save opportunities using localStorage.
- Display an empty-list message.
- Responsive design for different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- localStorage

## Project Files

- `index.html` - Application structure.
- `style.css` - Styling and responsive design.
- `script.js` - Application functionality.
- `README.md` - Project documentation.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Start adding and managing opportunities.
